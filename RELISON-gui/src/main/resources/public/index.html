Coordinates use decimal degrees. The street-map choice supports ±85.05112878° latitude; Equal Earth and Globe support ±90°. Globe anchors nodes to the surface without altitude attributes. Forces, node dragging and packing are disabled. Earth maps work offline; enable online street maps in Settings for street detail.

            

                
                
                
                
                
                
                
            

            

                
                
                
                
                
                
                
                
            

            

                
                
                
                
                
                
                
                
                
                
            

            

                
                
                
                
            

            

                
                
                
                
                
            

            

                
                
                
                
            

            
Animates a RELISON session. Stop keeps displayed positions. Overlap removal and component packing run at the end. For force models, theta enables approximate repulsion; zero uses exact pairs. Overlap radius is in layout units.

            
RELISON computes x/y/z positions. Fruchterman–Reingold 3D uses exact pairwise repulsion; stress majorization uses quadratic memory. Overlap removal separates spheres in layout units; nodes may still cover one another from some camera angles.

            

                
                
            

            

                
                
                
                
                
            

            
Lowest nonconstant Laplacian eigenvectors give the axes. Degree-normalized mode solves Lx = λDx. Directions are ignored; parallel and reciprocal strengths accumulate, and loops are ignored. Components are solved separately and translated side by side. Arbitrary pins are unsupported. Repeated eigenvalues allow equivalent rotated layouts. The solver reports limit reached if residuals remain above tolerance.

            
Like circle packing in 3D: without grouping, fills one compact ball. With a community or attribute, fills one ball per group and distributes the clusters around a sphere. Spacing is the minimum surface gap. Cluster sizes determine separation; groups are not placed in a line.

            
Miller et al. (2022): spherical angular SGD, unit pair weights, diameter-scaled distances and piecewise learning rate. Requires a connected graph; directions are ignored. Radius affects display scale. Quadratic distance storage. Warm starts must be nonzero; pinned positions must lie on the sphere.

            

                
                
                
                
            

            
Munzner (1997): a BFS spanning forest, hyperbolic hemisphere bands and Klein-ball projection. Non-tree links do not influence placement. Select a node and use Focus for a hyperbolic change of focus; ordinary orbit controls still rotate the view. Radius is the displayed ball radius. Pins, overlap removal and dragging would invalidate this geometry. Very deep hierarchies can exceed double precision.

            
Dujmovic–Wood (2005), Theorem 3.1: upward prime-modulus grid. Requires a directed acyclic graph; cycles and self-loops are rejected. Every arc increases z. Nonincident straight edges do not intersect in exact arithmetic; parallel edges coincide. This is not a Sugiyama layering heuristic.

            
This runs the original 2D layout unchanged and places every node on the z = 0 plane. Orbit the camera to inspect the layout in 3D.

            

            
Each hop level is arranged on a centred grid. Z increases by the Z-axis multiplier per hop; unreachable nodes share a grid one layer below the root.

            
Each feature value occupies a depth level. Nodes with that value form a centred x/y grid.

            
Uses the community composition layout in x/y and separates each community onto its own depth layer.

            
Shortest-path distances ignore edge direction. Optional edge weights are positive path lengths. Each disconnected component is optimized independently. These full-distance models require quadratic memory; stress majorization also factors a dense matrix.

            
Hu's edge-collapsing model: coarsen, draw, then refine. Each frame is one sequential force sweep. The total iteration budget spans all levels; increase it if refinement stops early. No gravity or movement cap is added.

            
Choose a community assignment or node attribute under Group by. Draws each group, lays out the community graph, then separates community envelopes. Published child models retain their default settings. Returns the final composition.

            
            
            
            
            
Metric ties retain ID order. Feature grids order nodes within each group; ego grids order nodes within each hop column or 3D layer. Choosing a metric overrides crossing-reduction passes.

            
Groups occupy rings from inside to outside, ordered by group label. Without grouping, all nodes share a ring.

            
Each feature value occupies a column, ordered by group label. Edges within a column are allowed.

            
Columns show hop distance from the root. Unreachable nodes share a final column.

            
Rings show hop distance from the root. Unreachable nodes share an extra outer ring.

            
Bipartite can detect two sides automatically. Multipartite requires grouping. Groups must not contain an edge between their own nodes.

            
Requires a tree or forest. Directed edges must point from parent to child, with one parent per node. Cycles are rejected.

            
Directed graphs only. Cycles are handled internally; original edge directions are retained. Ordering passes reduce crossings. The API also returns edge polylines; the viewers currently draw their usual edges.

            
            
            
Restore saved coordinates or choose a numeric node attribute for each axis. Attribute values are used directly and must be finite for every node. Save positions first when using a saved axis.

            

                
                

                
Moves each component as a unit, preserving its internal shape. Separate components may no longer share the same columns or coordinate axes.
