NumberOfGroups

Declared groups, including empty groups. Pass true to count only nonempty groups.

The two Gini metrics use RELISON's normalized Gini coefficient: zero means equal group mass and one means maximal inequality. They return zero for zero total mass or fewer than two groups. Entropy and assignment coverage return zero when their denominator is zero. Restricted graph metrics

EdgePartitionSubgraphGenerator preserves direction, weights, edge types, parallel edges, loops, and available attributes. It excludes edges from other groups even when both endpoints occur in the selected group. The graph metric supplier is called for each group so graph-specific caches are never shared. Existing graph metrics retain their usual interpretation and graph-type support. Undefined empty-graph values are represented as NaN by the library.

Edge references must refer to edges in the supplied graph. Count-only metrics assume the partition belongs to the current graph, just as community metrics do. Metrics that inspect edges validate membership against the live graph and resolve stable multigraph ids to their current parallel-edge indices.

Computation cost

Size and edge share read stored group sizes and the graph's edge counter: O(1) for one group and O(number of groups) for all groups. Declared group count is O(1). Nonempty group count, assignment coverage and size entropy use only group counts; size Gini additionally sorts these counts. None traverses the network's edges or builds node memberships.

Other metrics request only the snapshot detail they use: edge lists for weights and intra-partition graph metrics, endpoint sets for coverage and connectivity, and node-to-group memberships for overlap metrics. Weight Gini reads each assigned edge weight once. Intra-partition metrics retain the underlying graph metric's computation cost.

GUI

Detect partitions in Edge partitions, then compute their metrics in Metrics → Edge partition metrics. Multiple partitions can be retained during the loaded-graph session. Global values, finite per-group averages, and individual values are shown in the Metrics tab and can be exported to CSV; computed group values are also columns in the edge-group table and properties in its inspector. Graph metrics are available with the prefix Intra-partition and retain their parameter controls. Undefined results appear as a dash and are excluded from GUI averages. Structural graph edits invalidate retained partitions and their results. The inspector reuses group-edge and endpoint indexes. Metric computation updates the metric chart once and refreshes the inspector when its tab is opened.

Nonnumeric edge attributes are available directly in the Edge partitions tab's exploration selector under Edge attributes, and are grouped lazily when selected. Network and Metrics edge-partition selectors include only explicitly detected partitions, excluding these direct attribute groups. Use By edge attribute in Network and Edge attribute metrics in Metrics for attributes; the explorer's View in Metrics button opens attribute metrics when an attribute is selected. The detection controls offer Numeric edge attribute bins with a positive bin width. EdgeAttributePartitionDetector(attribute, binWidth) provides the same binning in RELISON-sna: intervals are anchored at zero and are lower-inclusive, upper-exclusive; missing values share an Unknown group. Attribute edits invalidate cached groups of that attribute. Renaming a string/categorical group updates its edge values and rebuilds its partition, merging equal categories.
